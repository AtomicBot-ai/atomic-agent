# Реорганизация atomic-agent

Status: verified
Owner: repository maintainers

Цель: агент быстро находит владельца поведения, получает только нужные инструкции и проверяет изменения достоверными командами. Отдельные packages и монорепозиторий не входят в программу.

Этапы проходят состояния `planned → specified → in-progress → verified`. Следующий подробный план создаётся после завершения предыдущего; наличие плана не означает реализацию.

Короткие инструкции, локальные справочники, архив, проверка документов. Бюджеты, покрытие прежних разделов, рабочие ссылки, выбранные проверки контрактов и обнаружение инструкций проверены. Согласованное перенаправление теста defaults выполнено без снижения покрытия.
