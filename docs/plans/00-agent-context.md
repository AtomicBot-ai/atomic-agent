## Контракт результата

Корневой AGENTS.md ≤ 8 KiB: назначение, общие инварианты, команды и маршруты. Локальные AGENTS.md ≤ 4 KiB: ограничения области, условия чтения справочников и проверки; без повторения корня. Каждая цепочка инструкций ≤ 24 KiB. README подсистемы — точка входа; локальные docs — отдельные механизмы. Корневые docs — архитектура, разработка, user guides, планы, предложения и архив. Локальные инструкции читаются явно для всех затронутых областей; автоматическая загрузка из корня не предполагается.

3. Создать локальные AGENTS и README: agent, runtime, config, prompt, session, llm, local-llm, memory, tools, tui, channels, mcp, skills, tasks, http, tracing, approval, scripts. Остальные области получают локальный справочник и маршрут.
